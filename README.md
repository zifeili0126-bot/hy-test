# 项目订单交互原型

- 入口：[index.html](index.html)，可直接用浏览器打开，无需启动服务。
- 对应说明：[交互说明.md](交互说明.md)。
- 对应 Demo 文档：`03-prd（PRD工作区）/项目订单/前端项目订单_Demo版PRD.md`。
- 视觉留档：`验收截图/`。

本次范围为项目列表、项目详情、具体事项详情三个层级。首页、发布、设置仅保留栏目位置。

项目、人员、报价、付款比例、交付日期、修改次数和成果缩略图均为演示数据，不是已确认的业务标准。签署、反馈、付款通知等操作只改变原型演示状态，不连接真实服务。

业务模式：客户购买全阶段设计服务，费用分阶段支付。阶段推进不重新购买，不重新签订全项目合同。
